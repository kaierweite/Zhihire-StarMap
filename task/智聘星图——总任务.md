# 第十五届中国软件杯B2赛题

# 《智聘星图——基于银河麒麟操作系统的AI智能匹配与能力图谱平台》

# 21天开发计划（AI辅助版）

------

# 一、项目最终功能范围

## 用户端

- 注册登录
- 上传简历（PDF/DOC）
- AI解析简历
- 能力图谱展示
- 岗位推荐
- AI职业规划

## 企业端

- 注册登录
- 上传岗位JD
- AI解析岗位需求
- 候选人推荐
- 人才搜索

## 管理端

- 用户管理
- 企业管理
- 数据统计
- 系统日志

------

# 二、技术栈

**前端：**
Vue3 + TypeScript + ElementPlus + ECharts + Axios

**后端（主服务）：**
Java 21 + Spring Boot 3 + MyBatis-Plus + KingbaseES + Redis + JWT + Knife4j

**AI服务（微服务）：**
Python 3.12 + FastAPI + LangChain + DeepSeek API + sentence-transformers

**文档解析：**
docling + pdfplumber + python-docx

**能力图谱：**
networkx + scikit-learn + ECharts Graph

**部署：**
Docker + 银河麒麟 V11
