# 第二阶段：视频脚本（1小时）

## 任务1：完整脚本

```text
# 智聘星图 - 演示视频脚本

## 开场（30秒）

画面：项目Logo + 主标题
配音：各位评委老师好！我们带来的作品是《智聘星图——基于银河麒麟操作
系统的AI智能匹配与能力图谱平台》。本作品针对传统招聘中简历筛选效率低、
能力评估不直观等痛点，提供了AI智能匹配与可视化能力图谱的解决方案。

## 一、登录注册（1分钟）

画面：打开浏览器 → 访问 http://localhost → 注册页面 → 登录页面
配音：系统支持三种角色：求职者、企业和管理员。我们先注册一个求职者账号。
（操作演示：填写注册信息 → 提交 → 登录）
页面简单明了，注册后自动登录进入主界面。

## 二、上传简历与AI解析（2分钟）

画面：进入简历中心 → 拖拽上传PDF简历 → 等待解析 → 查看解析结果
配音：这是核心功能之一。用户上传PDF或Word简历后，系统调用本地部署的
Qwen2.5大模型进行解析。
（等待解析动画）
大家可以看到，AI成功提取了技能标签、学历信息、工作经历和项目经历。
相比传统人工录入，效率提升了数倍。而且所有数据都在本地处理，保障了
信息安全。

## 三、能力图谱展示（1.5分钟）

画面：进入能力图谱 → 技能树 → 雷达图 → 关系图
配音：能力图谱是本作品的一大亮点。我们提供了三种可视化方式。
首先是技能树，展示技能的层级关系。
其次是雷达图，从多个维度评估用户能力。
最后是技能关系图，直观展示用户掌握的技能及其关联关系。
这三种视图帮助用户全面了解自己的能力结构。

## 四、岗位推荐（1.5分钟）

画面：进入岗位推荐 → 查看推荐列表 → 点击查看匹配详情
配音：基于AI解析出的用户技能，我们的推荐算法从技能匹配度（50%）、
经验匹配度（20%）、学历匹配度（20%）和城市匹配度（10%）四个维度
加权计算综合评分。
（点击查看详情）
这里可以看到具体的匹配详情，包括已匹配的技能和缺失的技能。
匹配度达到80%以上的岗位会被标记为"高度匹配"。

## 五、AI职业规划（1.5分钟）

画面：进入职业规划 → 设置目标岗位 → 生成规划 → 浏览完整规划
配音：AI职业规划功能是本作品的创新点之一。用户设定目标岗位后，
AI会分析用户当前技能与目标岗位的差距，生成个性化的学习路径。
（浏览规划内容）
包括急需技能、推荐技能、分阶段学习路线、以及未来的职业发展方向。
比如，该用户如果想成为架构师，AI建议补充系统设计能力和分布式架构知识。

## 六、企业端操作（1.5分钟）

画面：切换到企业账号 → 发布岗位 → 查看AI解析结果 → 人才推荐
配音：接下来演示企业端功能。企业用户发布岗位JD后，系统同样会调用AI
进行解析，提取技能要求、学历要求等信息。
（查看人才推荐）
基于岗位需求，系统会自动推荐匹配的候选人，并显示匹配度和技能对比。
这大大降低了HR的筛选成本。

## 七、后台管理（1分钟）

画面：切换到管理员账号 → 数据看板 → 用户管理 → 日志查看
配音：管理员可以查看系统运行的整体数据，包括用户数量、岗位数量、
匹配次数等统计信息。同时支持用户管理、企业审核和系统日志查看。
数据看板直观展示了平台的运行状态。

## 八、技术架构（30秒）

画面：技术架构图
配音：技术方面，我们采用了前后端分离架构。前端使用Vue3 + ElementPlus，
后端使用Spring Boot 3 + MyBatis-Plus，AI服务使用FastAPI + Ollama
部署的Qwen2.5大模型。数据库使用PostgreSQL，缓存使用Redis。
所有服务通过Docker编排部署，支持银河麒麟V11操作系统。

## 九、创新总结（30秒）

画面：创新点列表
配音：本作品的核心创新点包括：
第一，本地部署AI大模型，确保数据安全可控；
第二，多维度智能匹配算法，提高推荐精准度；
第三，能力图谱可视化，让能力评估更直观；
第四，AI职业规划助手，为个人成长提供指导；
第五，全面适配银河麒麟国产操作系统。

## 结尾（15秒）

画面：项目信息 + 致谢
配音：以上就是智聘星图的完整演示。感谢各位评委老师的观看！
```

- AI加载过程展示Loading动画

2. 按脚本顺序排列

10. 导出：MP4, 1920x1080, H.264

总时长：10-12分钟
