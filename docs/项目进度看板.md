## 💡 开发建议

1. **MVP 优先**：先实现单条 Demo 链路（上传简历 → AI解析 → 图谱展示 → 推荐），再横向覆盖全部功能
2. **AI 服务独立**：先 mock AI 接口返回值，前后端联调通后再接入真实大模型
3. **每日提交**：每天至少一次 Git 提交，保持代码可追溯
4. **文档同步**：代码变更同步更新设计文档
