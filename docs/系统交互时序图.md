# 智聘星图 — 系统整体交互时序图

```mermaid
sequenceDiagram
    %% 角色定义
    participant Visitor as 访客
    participant JobSeeker as 求职者
    participant Company as 企业用户
    participant Admin as 管理员
    participant Frontend as Vue3 前端
    participant Backend as Spring Boot 主服务
    participant DB as KingbaseES
    participant AI as FastAPI AI微服务
    participant LLM as DeepSeek/Ollama

    Note over Visitor,LLM: ======== 认证流程 ========
    Visitor->>Frontend: 注册/登录
    Frontend->>Backend: POST /api/auth/register | login
    Backend->>DB: 写入/查询用户
    Backend->>Backend: BCrypt加密 / JWT签发
    Backend-->>Frontend: 返回 Token + 角色
    Frontend-->>JobSeeker: 跳转求职者端
    Frontend-->>Company: 跳转企业端
    Frontend-->>Admin: 跳转管理端

    Note over JobSeeker,LLM: ======== 求职者端流程 ========
    JobSeeker->>Frontend: 上传简历(PDF/DOC)
    Frontend->>Backend: POST /api/resume/upload
    Backend->>DB: 保存文件记录
    Backend-->>Frontend: 上传成功

    Backend->>AI: POST /ai/parse/resume
    AI->>AI: 文档文本提取
    AI->>LLM: 调用大模型提取结构化信息
    LLM-->>AI: JSON结构化数据
    AI-->>Backend: 解析完成
    Backend->>DB: 更新解析状态+技能标签

    JobSeeker->>Frontend: 查看能力图谱
    Frontend->>Backend: GET /api/graph/user
    Backend->>DB: 查询技能数据
    DB-->>Backend: 返回技能图谱数据
    Backend-->>Frontend: 返回 ECharts JSON
    Frontend->>Frontend: ECharts渲染雷达图/关系图

    JobSeeker->>Frontend: 查看岗位推荐
    Frontend->>Backend: GET /api/recommend/jobs
    Backend->>AI: POST /ai/recommend/match
    AI->>AI: 多维评分(技能50%+经验20%+学历20%+城市10%)
    AI-->>Backend: 推荐列表+匹配度
    Backend-->>Frontend: 排序推荐结果

    JobSeeker->>Frontend: 查看AI职业规划
    Frontend->>Backend: GET /api/career/plan
    Backend->>AI: POST /ai/career/analyze
    AI->>LLM: 技能缺口分析+学习路线推荐
    LLM-->>AI: 规划建议
    AI-->>Backend: 返回规划结果

    Note over Company,LLM: ======== 企业端流程 ========
    Company->>Frontend: 上传岗位JD
    Frontend->>Backend: POST /api/job/create
    Backend->>DB: 保存岗位
    Backend->>AI: POST /ai/parse/job
    AI->>LLM: 提取技能/学历/经验需求
    LLM-->>AI: 结构化需求数据
    AI-->>Backend: 解析完成

    Company->>Frontend: 查看人才推荐
    Frontend->>Backend: GET /api/recommend/talents
    Backend->>AI: POST /ai/recommend/talent-match
    AI-->>Backend: 推荐候选人+评分
    Backend-->>Frontend: 人才推荐列表

    Note over Admin,Admin: ======== 管理端流程 ========
    Admin->>Frontend: 用户/企业管理
    Frontend->>Backend: GET/PUT /api/admin/users
    Backend->>DB: 查改用户数据
    Backend-->>Frontend: 用户管理界面

    Admin->>Frontend: 查看数据统计
    Frontend->>Backend: GET /api/admin/stats
    Backend->>DB: 统计数据
    Backend-->>Frontend: ECharts统计图表
