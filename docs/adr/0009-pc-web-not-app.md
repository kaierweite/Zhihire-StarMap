# ADR-0009: 选 PC Web 不做原生 App

**日期**：2026-07-01
**状态**：已采纳
**关联**：V4 决策记录 Q7

## 背景

赛题要求「支持本地大模型服务部署或调用云端大模型服务，具备 PC Web 或 App 可视化界面，方便用户访问与操作」，PC Web 与 App 为二选一。全套设计已面向 PC Web，但此前无任何 ADR 或文档显式声明该选择及理由。

## 决策

选 PC Web（B/S 架构），不做原生 App。

- 赛题用「或」给了二选一，PC Web 在 LoongArch 麒麟虚机浏览器跑得起来即可满足。
- 四核 8GB 跑不起移动端构建链。
- Vue3 一套代码同时撑 PC 演示与答辩。
- 前端 Vue3 响应式布局兜底，手机浏览器能跑基本形态（应对评委手机能不能开）。

## Considered Options

- **A 选 PC Web（采纳）**：赛题二选一满足即可，PC Web 在麒麟虚机浏览器跑得起来，8GB 不跑移动端构建链。
- **B 做 App**：四核 8GB 跑不起移动端构建链，且答辩演示用 PC 更直观。
- **C 两者都做**：人力与时间不允许，21 天排期无余量。

## Consequences

- 需求文档补声明「界面形态：PC Web（B/S），不做原生 App」。
- 前端 Vue3 走响应式布局，手机浏览器能跑基本形态作为兜底。
- 不引入任何移动端原生框架（React Native / Flutter / uni-app）。
