# 原型设计目录

> 原型统一用 HTML + Tailwind + 共享 `config.js` 设计令牌绘制，一屏一文件，做成可点可看的富原型（rich prototype），可直接演进到 Vue3 真页。
> **不再使用 draw.io 矢量稿**（原规划的 21 页 drawio 占位路径已弃用）。

共 30 个 HTML 文件（26 基础 + 4 面试模块，ADR-0011），分 common / user / company / admin 四端。基础面：18 项一级菜单 / 独立页 + 5 项二级页与特色页；面试模块新增 3 项一级页 + 1 项二级页。对应 V4 22 条决策 + ADR 0001-0011。

## 命名口径

- 术语统一为「岗位 / 人才」对称对仗：user 端「岗位推荐 / 岗位搜索」对应 company 端「人才推荐（候选人推荐）/ 主动寻访」。
- 状态/角色字面沿用 V4 口径：VARCHAR 语义化枚举（NORMAL/DISABLED/BANNED、UNVERIFIED/PENDING/VERIFIED/REJECTED、OPEN/CLOSED/DRAFT、ACTIVE/CANDIDATE/MERGED 等）。

## 页面清单

### common/ — 公共页（3 项，独立页）

- 首页着陆页.html — 系统首页，品牌与三大核心能力入口
- 登录.html — 求职者 / 企业 / 管理员三角色登录，右侧承担产品介绍
- 注册.html — 求职者 + 企业双角色注册

### user/ — 求职者端（17 页）

所有页面共享统一导航栏：探索 / 职位推荐 / 职位搜索 / 简历中心 / 面试功能（下拉） / 社交。

**一级菜单页（10 项）：**

- 个人中心.html — 身份档案：城市选择器 + 完成度进度条 + 基本资料
- 简历中心.html — 简历上传 + AI 解析（管理 resume + upload_file）
- 能力图谱.html — 类型化边知识图谱（SVG）+ 缺口视图 + PREREQUISITE 前置链 + 覆盖率分析
- 职位推荐.html — 系统主动推荐，四维子分（技能/学历/经验/城市）+ 匹配依据 + 图谱建议
- 职位搜索.html — 求职者主动检索岗位，AI 语义搜索 + 多维筛选
- AI职业规划.html — AI 智能职业规划，图算法缺口分析 + 学习路线
- 社交.html — 社交功能页
- 模拟面试.html — 面试入口：选岗位/职业角色 + 聊天式问答界面（ADR-0011）
- 面试题库.html — 按岗位/职业角色/题型的题目卡片列表（ADR-0011）
- 简历优化.html — 按 section 的改写建议（ADR-0011）

**二级页与特色页（7 项）：**

- 岗位详情.html — 从职位推荐/职位搜索点进；含四维匹配详情面板 + 图谱学习建议
- 通知中心.html — 顶部铃铛入口；`GET /api/notification/unread-count` 每 30s 红点轮询
- 面试报告.html — 模拟面试二级页：能力雷达图 + 五维量化评测 + 反馈建议 + 学习路径入口（ADR-0011）
- 面试-聊天式.html — 聊天式模拟面试界面（ADR-0011）
- 面试-纯音频电话.html — 纯音频面试界面（ADR-0011 愿景）
- 面试-视频面试.html — 视频面试界面（ADR-0011 愿景）
- 面试记录.html — 历史面试记录列表

### company/ — 企业端（一级菜单 4 项）

- 企业首页.html — 招聘中心 + 企业信息编辑 + 审核状态条
- 主动寻访.html — 不绑定具体岗位的开放式人才搜索 + 候选人对比（原「AI 淘金寻宝」）
- 岗位发布.html — 手动填写 / JD 上传双模式
- 岗位管理.html — 岗位列表 + 编辑 + 状态切换；编辑弹窗内「查看能力图谱」承载岗位能力图谱；某岗位点进「查看候选人」转候选人推荐二级页

company 端二级页：

- 候选人推荐.html — 从岗位管理某岗位进；反向共用同一份 match_result，含可解释评分详情
- 企业通知中心.html — 顶部铃铛浮标入口（不在一级侧边栏）

### admin/ — 管理端（一级菜单 4 项）

- 管理员仪表板.html — 数据统计聚合 + service 状态卡片
- 审核管理.html — 企业审核 Tab + 技能字典审核 Tab（候选词审核 + 同义合并）
- 用户管理.html — 用户列表 + 搜索 + 封禁；底部承载岗位下架（数据维护落点，对接 V4「岗位下架 / 用户封禁」）
- 系统日志.html — AOP 切面落库的查询入口（对接 V4 Q18）

## 愿景 / 派生页口径

- 已删除整页：人脉（社交关系图谱无数据源）、职场资讯（外部宏观数据仪表盘无数据源）、洞察（派生功能页，非闭环依赖）、校园招聘（愿景展示页，非闭环依赖）。
- 社交.html 保留为面向求职者的社交功能页；已剔除无数据源的模块（薪资预测、热钱/冷灶指数、人脉迁徙热力图、压力面试数字人、反向背调、同温层去向、面试官心理画像、组织生命周期等），避免无源功能在演示中被追问。
- 简历中心已完成瘦身：移除内嵌的能力图谱 / 职业规划 tab，这两块作为独立页（能力图谱.html / AI职业规划.html）承载，个人中心承载 REQ-022 身份档案。
