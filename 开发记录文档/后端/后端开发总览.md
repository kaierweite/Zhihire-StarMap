# 后端开发总览

> 本目录包含智聘星图后端（FastAPI）每个模块的 API 开发规划文档。
> 前端 39 个 `.vue` 页面已全部完成（模拟数据），后端需要逐模块对接。

---

## 技术栈

- **框架**：FastAPI + Uvicorn
- **ORM**：SQLAlchemy 2.0（async）
- **迁移**：Alembic
- **数据库**：KingbaseES（PostgreSQL 兼容）
- **认证**：python-jose + passlib（bcrypt）
- **缓存**：aiocache（内存）
- **AI**：云端 DeepSeek API（含 chat + vision）
- **文档解析**：pdfplumber + python-docx
- **知识图谱**：networkx（常驻内存）

---

## 分层架构

| 层 | 目录 | 职责 |
|----|------|------|
| 路由层 | `app/api/v1/` | 参数校验 + 响应封装（Result[T]） |
| 服务层 | `app/services/` | 编排 core + infrastructure |
| 核心算法 | `app/core/` | 解析/归一/图谱/匹配/职业规划 |
| 基础设施 | `app/infrastructure/` | llm / cache / storage 防腐 |
| 模型 | `app/models/` | entities(ORM) / schemas(Pydantic) / enums |
| 仓储 | `app/repositories/` | 原子数据库操作 |

## 开发顺序建议

```
day00 基础设施（数据库连接 / JWT 依赖 / 配置入口）
  ↓
day01 auth 认证（所有接口的前置依赖）
  ↓
day02 user 用户档案 ← day10 company 企业信息（可并行）
  ↓
day03 resume 简历解析（核心数据入口，依赖 LLM + 文档解析）
  ↓
day05 job 岗位（另一个数据入口）
  ↓
day04 graph 能力图谱（依赖 skill / skill_relation 数据）
  ↓
day06 match 双向匹配（依赖图谱 + 简历 + 岗位）
  ↓
day07 career 职业规划（依赖图谱缺口分析 + LLM）
  ↓
day08 interview AI 面试（依赖 LLM）
  ↓
day09 notification 通知（依赖认证）
  ↓
day11 admin 管理员后台
```

## 统一约定

- API 前缀：`/api`
- 统一返回：`{ code: 200, message: "success", data: T }`
- 分页返回：`{ records, total, page, size }`
- 状态字段：VARCHAR 语义化枚举（大写）
- 角色枚举：ADMIN / USER / COMPANY
- 密码加密：bcrypt
- 认证：JWT `Authorization: Bearer <token>`，claim 角色大写
- 中文注释：逐逻辑语句 + 函数 docstring
