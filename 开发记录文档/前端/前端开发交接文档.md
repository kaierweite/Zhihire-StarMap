```
## 目录结构
```
frontend/
├── src/
│   ├── api/              # API 接口封装
│   ├── views/

│   ├── components/       # 通用组件

```
## 原型页面清单（设计参考）
原型在 prototype/ 目录，按端分文件夹：
- common/（3 页）：首页着陆、登录、注册
- user/（17 页）：个人中心、简历中心、能力图谱、职位推荐、职位搜索、AI职业规划、社交、模拟面试、面试题库、简历优化、岗位详情、通知中心、面试报告、面试-聊天式、面试-纯音频电话、面试-视频面试、面试记录
- company/（6 页）：企业首页、岗位管理、岗位发布、智能筛选、候选人推荐、企业通知中心
- admin/（4 页）：管理员仪表板、审核管理、用户管理、系统日志

## 导航结构
所有 user 页面共享统一导航栏：探索 / 职位推荐 / 职位搜索 / 简历中心 / 面试功能（下拉） / 社交 + 通知铃铛
company 页面：企业首页 / 岗位管理 / 岗位发布 / 智能筛选 + 候选人推荐（侧边栏）
admin 页面：管理员仪表板 / 用户管理 / 审核管理 / 系统日志

## 后端 API 约定
- 基础路径：/api/
- 认证：JWT token，放在 Authorization: Bearer <token>
- 分页：page + size 参数，返回 {code, data: {records, total, page, size}}
- 统一返回：{code: 200, message: "success", data: ...}
- 角色：ADMIN / USER / COMPANY（大写）

## 当前后端已完成的 API（可对接）
- POST /api/auth/register — 注册
- POST /api/auth/login — 登录（返回 token + role）
- GET /api/ping — 健康检查
```
