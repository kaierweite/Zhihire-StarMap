# Zhihire StarMap（智聘星图）

基于银河麒麟操作系统的 AI 智能匹配与能力图谱系统。

> 第十五届中国软件杯大赛 B2 赛题作品
> 出题企业：麒麟软件有限公司

---

## 项目简介

智聘星图（Zhihire StarMap）是一个基于 AI、大模型和知识图谱技术的人才智能招聘平台。

系统通过：
- 简历智能解析（PDF/DOC/DOCX）
- 岗位需求结构化分析
- 能力图谱生成（节点/边/权重）
- 人岗智能匹配与评分
- AI 职业规划与面试辅助

帮助求职者和企业实现精准招聘与人才推荐。

---

## 核心功能

### 求职者端
- 用户注册登录
- 简历上传与解析
- 个人能力图谱
- 岗位智能推荐
- AI 职业规划
- AI 面试助手

### 企业端
- 企业认证
- 岗位发布
- 岗位能力图谱
- 人才智能推荐
- 候选人管理

### 管理端
- 用户管理
- 企业管理
- 数据统计
- 系统监控
- 日志管理

## 技术栈

### 系统架构
```
Vue3 (前端)
  ↓ HTTP
Spring Boot 3 (主服务)
  ↓
┌──────────────────┐
│   KingbaseES     │
│   (人大金仓)     │
└──────────────────┘
  ↓ HTTP
FastAPI (AI 微服务)
  ↓
LLM + NLP + 推荐算法
```

### 前端
- Vue 3
- TypeScript
- Vite
- Element Plus
- ECharts

### 后端（主服务 — Java 21）
- Java 21
- Spring Boot 3
- MyBatis-Plus
- JWT（权限认证）
- Redis（缓存）
- Knife4j（API 文档）
- KingbaseES（人大金仓数据库）

**负责模块：** 登录注册、权限认证、文件管理、岗位管理、推荐结果展示、后台管理、API 接口

### AI 服务（独立微服务 — Python 3.12）
- Python 3.12
- FastAPI
- LangChain
- sentence-transformers
- docling
- pdfplumber
- networkx

**负责模块：** 文档解析（PDF/DOC/DOCX）、技能提取、能力图谱（节点/边/权重）、智能推荐（岗位推荐/人才推荐/匹配评分）

### 部署环境
- 银河麒麟高级服务器操作系统 V10/V11
- LoongArch（龙芯，四核 / 8GB+ / 256GB+）
