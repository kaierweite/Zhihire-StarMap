# 智聘星图部署架构

> 口径以 ADR-0007（裸部署优先）+ V4 Q9（内存预算待实测）+ V4 Q20（Redis 可选）为准。
> 裸部署优先，Docker 仅可选非推荐路径。
> AI 能力内置于 FastAPI 主服务，不再独立部署。

## 一、整体拓扑

```
                    ┌──────────────────────────────────────┐
                    │     麒麟虚机 (LoongArch 四核 8GB)     │
                    │                                      │
   ↕ HTTP :80/:443 │  Nginx (宿主, 跑静态 + 反向代理)      │
                    │      │                              │
                    │      └──→ FastAPI 主服务 (systemd) ──┤
                    │             KingbaseES (宿主)        │
                    │             Redis (可选, 宿主)      │
                    └──────────────────────────────────────┘
                                   │
                            云端 DeepSeek API
```

- 前端静态资源由 Nginx 宿主发布。
- FastAPI 主服务（含 AI 能力）以 `systemd` 裸跑，暴露 :8000。
- KingbaseES 以宿主服务启动，默认 :54321。
- Redis 以宿主服务启动，默认 :6379（可选组件，装不上则 aiocache 内存缓存兜底）。
- 文件存储路径 `/data/starmap/files/`。

## 二、内存预算（总分 ≤ 8GB，硬约束来自 ADR-0007）

> 以下为「参考估值」，day1-2 冒烟关卡实测后回填至本文件。
> 实测后升格为约束。

| 组件 | 峰值预算 | 说明 |
|------|---------|------|
| KingbaseES | ~1.0~1.5GB | 调保守默认：`shared_buffers=512MB`、`max_connections=30`，常驻压到 ~1GB |
| FastAPI 主服务 | ~1.5GB | 含常驻 networkx 内存图 + uvicorn --workers 1 + AI 客户端 |
| Redis | ~0.5GB | 可选组件，不装则 aiocache 内存兜底，预算释放给系统 |
| Nginx | ~0.3GB | worker x N |
| 系统 + 峰值余量 | ~2.0~2.2GB | 内核/文件缓存/解析峰值/召回峰值 |
| **合计** | **≤8GB** | 常驻争取压到 5GB 内，留 3GB 给峰值 |

超预算优先调：FastAPI 进程数 → KingbaseES shared_buffers → Redis 取舍。

## 三、systemd 服务拓扑

- `starmap-backend.service` → `uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1`，依赖 kingbase 起后起。
- `kingbase.service` / `nginx.service` 走麒麟包管理。
- `redis.service` 可选：install.sh 探测得性，装得上就配，装不上不配。

## 四、网络端口

| 服务 | 端口 | 对内 / 对外 |
|------|------|-----------|
| Nginx | 80 / 443 | 对外 |
| FastAPI 主服务 | 8000 | 仅内网（Nginx 反代） |
| KingbaseES | 54321 | 仅内网 |
| Redis | 6379 | 仅内网，可选 |

## 五、与旧方案的差异（V4 后）

- 删「Docker 五容器」默认路径，改裸部署优先。
- 删「Ollama / 本地大模型」部署点，AI 全走云端。
- 删 `sentence-transformers` 依赖（连带 PyTorch），避免 loongarch64 上装不上。
- 后端由单一 FastAPI 主服务（AI 能力内置）。
- Redis 从「必占」降级为「可选占」，装不上则 aiocache 内存兜底（V4 Q20）。
- 内存预算从「写死 ~3GB」降级为「参考估值等待实测」后升格（V4 Q9）。
